# Coffee Shop Sales Analysis Dashboard

## Project Overview
An interactive Excel sales analysis dashboard developed to analyze revenue patterns, order volumes, and customer footfall across multiple coffee shop locations.

## Key Insights & Metrics Tracked
- **Total Revenue & Volume:** Analyzed $698,812.33 in total sales and 149,116 customer footfall.
- **Location-Wise Performance:** Evaluated sales and transaction density across Astoria, Hell's Kitchen, and Lower Manhattan.
- **Key KPIs:** Average bill per person, peak hours, footfall trends, and top-selling product categories.

## Tools & Techniques Used
- **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers, KPI-style cards, Data Modeling, and Conditional Formatting.

## Repository Contents
- `Coffee Shop Sales1.xlsx`: Raw dataset along with calculated fields and pivot models.
